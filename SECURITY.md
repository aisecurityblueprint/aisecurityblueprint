# Security Policy

Only the latest version on the default branch is actively maintained.

Do not open public issues for suspected vulnerabilities, exposed credentials, authentication bypasses, prompt-injection paths, data exposure, or deployment weaknesses. Report them privately to the repository owner with the affected component, reproduction steps, impact, sanitized evidence, and any suggested remediation.

Testing must remain within explicitly authorized systems. Do not access, modify, retain, or disclose data that does not belong to you.
